## ¿Que es RUBY?
Ruby es un lenguaje de Scripting es decir un lenguaje de programacion para escribir scrips (guiones o secuencias de comandos), pero orientado a codigo abierto y objetos, tambien es un lenguaje de programacion interpretado de alto nivel,  Ruby fue diseñado en la decada de los 1990 por Yukihiro Matsumoto en Japón con el objetivo de crear un lenguaje mas equilibrado y agradable para cualquier programador, centradose en la simplicidad y la eficiencia en la escritura de codigo, ademas Ruby destaca de otros lenguajes por su sintaxis elegante y natural ya que este facilita su escritura y lectura del codigo.

## Caracteristicas de RUBY
Principalmente el valor de Ruby es el hecho de estar centrado en la simplicidad y la productividad, lo que nos llega a facilitar trabajar con este lenguaje, sus caracteristicas son:
1. Ruby ejecuta instrucciones de forma directa y utiliza un tipado dinamico
2. Todo en Ruby es un objeto, incluyendo los tipos de datos basicos como pueden ser los numeros y las cadenas de texto
3. Este lenguaje de programacion permite alterar sus partes internas con total libertad, asi como definir metodos de forma dinamica
4. Tambien Ofrece una sintaxis limpia y legible, que hace que la programacion sea mas intuitiva y agil que con otras muchas alternativas
5. Utiliza recoleccion de basura para la gestion automatica de memoria

## Ventajas de RUBY
Entre las principales ventajas de Ruby, encontramos que su sintaxis intuitiva facilita muchísimo el aprendizaje y la escritura de código, especialmente para los desarrolladores que están empezando, su integración con el framework Ruby on Rails acelera de forma notable el desarrollo de aplicaciones web, ofreciendo una estructura clara y una gran cantidad de bibliotecas que simplifican la programación además, la naturaleza de código abierto de Ruby hace que su comunidad sea muy activa e implicada, lo que supone un enriquecimiento continuo de sus recursos​​

Pero asi como ventajas tiene desventajas como hay que decir que el rendimiento puede ser un problema, especialmente para aplicaciones que manejan grandes volúmenes de transacciones o datos en tiempo real, esto sucede porque este lenguaje de programación  puede ser más lento en comparación con otros como NodeJS o Python, además, aunque Ruby es flexible, esta característica puede llevar a dificultades cuando se trabaja en grandes equipos, donde las modificaciones en el código base pueden llevar a inconsistencias y dificultades en el mantenimiento​​.
